# 🏦 Bank Loan & Transaction Data Analysis

A complete Data Analytics project developed using **Excel, MySQL, Tableau, and Power BI** to analyze banking loan data and customer debit-credit transactions.

This project demonstrates the complete analytics workflow including data cleaning, SQL querying, KPI development, dashboard creation, and business insight generation.

---

# 📌 Project Overview

The project consists of two independent banking datasets:

## 1️⃣ Bank Loan Dataset
Analyzes loan portfolio performance, customer demographics, default risk, branch performance, and loan trends.

## 2️⃣ Credit & Debit Transaction Dataset
Analyzes banking transactions including credit, debit, transaction methods, branch performance, and suspicious transaction monitoring.
